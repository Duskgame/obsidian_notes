| APP.6.A3:<br>Sichere Beschaffung von Software                             | Diese Verträge oder Zusagen SOLLTEN insbesondere garantieren, dass auftretende Sicherheitslücken und Schwachstellen der Software während des gesamten Nutzungszeitraums zeitnah behoben werden.                                                                             |        |               |           |

| APP.6.A4:<br>Regelung für die Installation und Konfiguration von Software | die datensparsamsten Einstellungen (in Bezug auf die Verarbeitung von personenbezogenen Daten) konfiguriert werden sowie                                                                                                                                                    |        |               |           |
