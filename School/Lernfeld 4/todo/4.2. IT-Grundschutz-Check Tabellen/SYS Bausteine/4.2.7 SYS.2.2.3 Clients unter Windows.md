| SYS.2.2.3.A1:<br>Planung des Einsatzes von Cloud-Diensten unter Windows   | Da Windows-basierte Geräte eng mit den Cloud-Diensten des Herstellers Microsoft verzahnt sind, MUSS vor ihrer Verwendung strategisch festgelegt werden, welche enthaltenen Cloud-Dienste in welchem Umfang genutzt werden sollen bzw. dürfen.                               | nein      | IT-Leitung    | Keine strategische Festlegung zu Windows Cloud-Diensten dokumentiert; Online-Konten gesperrt, aber weitere MS Cloud-Dienste (OneDrive, Telemetrie etc.) nicht explizit geregelt           |
| SYS.2.2.3.A2:<br>Auswahl und Beschaffung einer geeigneten Windows-Version | Der Funktionsumfang und die Versorgung mit funktionalen Änderungen einer Windows-Version MÜSSEN unter Berücksichtigung des ermittelten Schutzbedarfs und des Einsatzzwecks ausgewählt werden.                                                                               | ja        | IT-Abteilung  | Windows 10 Pro 64 Bit gewählt; geeignet für Domäneneinbindung, GPO und Enterprise-Funktionen                                                                                             |
| SYS.2.2.3.A2Auswahl und Beschaffung einer geeigneten Windows-Version      | Die Umsetzbarkeit der erforderlichen Absicherungsmaßnahmen MUSS bei der Auswahl berücksichtigt werden.                                                                                                                                                                      | ja        | IT-Abteilung  | Windows 10 Pro unterstützt Domäne, Gruppenrichtlinien und BitLocker                                                                                                                       |
| SYS.2.2.3.A2Auswahl und Beschaffung einer geeigneten Windows-Version      | Basierend auf dem Ergebnis der Überprüfung MUSS der etablierte Beschaffungsprozess um die Auswahl des entsprechenden Lizenzmodells und „[[Service Branch (Windows)|Service Branches]]" (CB, CBB oder LTSC) erweitert werden.                                                                             | nein      | IT-Abteilung  | Kein Service Branch (CB/CBB/LTSC) dokumentiert; Update-Verzögerung auf Maximum gesetzt deutet auf ungeregelten Update-Kanal                                                               |
| SYS.2.2.3.A4:<br>Telemetrie und Datenschutzeinstellungen unter Windows    | Um die Übertragung von Diagnose- und Nutzungsdaten an Microsoft stark zu reduzieren, MUSS das [[Telemetrie|Telemetrie-Level]] 0 (Security) in der Enterprise-Edition von Windows konfiguriert werden.                                                                                      | nein      | IT-Abteilung  | Windows 10 Pro (nicht Enterprise) installiert; Telemetrie-Level 0 in der Pro-Edition nicht verfügbar; Telemetrie auf "Windows Standard"                                                  |
| SYS.2.2.3.A4:<br>Telemetrie und Datenschutzeinstellungen unter Windows    | Wenn diese Einstellung nicht wirksam umgesetzt wird oder bei anderen Windows-Edition umgesetzt werden kann, dann MUSS durch geeignete Maßnahmen, etwa auf Netzebene, sichergestellt werden, dass die Daten nicht an den Hersteller übertragen werden.                       | nein      | IT-Abteilung  | Keine Netzwerkmaßnahmen zur Einschränkung der Telemetrieübertragung dokumentiert                                                                                                          |
| SYS.2.2.3.A5:<br>Schutz vor Schadsoftware unter Windows                   | Sofern nicht gleich- oder höherwertige Maßnahmen, wie z. B. Ausführungskontrolle, zum Schutz des IT-Systems vor einer Infektion mit Schadsoftware getroffen wurden, MUSS eine spezialisierte Komponente zum Schutz vor Schadsoftware auf Windows-Clients eingesetzt werden. | ja        | IT-Abteilung  | Avira Antivirus (15.0.2003.1821) zentral gesteuert und installiert; ergänzt durch Avira Software Updater                                                                                  |
| SYS.2.2.3.A6:<br>Integration von Online-Konten in das Betriebssystem      | Die Anmeldung am System sowie an der Domäne DARF NUR mit dem Konto eines selbst betriebenen Verzeichnisdienstes möglich sein.                                                                                                                                               | ja        | IT-Abteilung  | Domäneneinbindung (Windows-Domäne); Online-Konten gesperrt; Profile auf Domänenserver gespeichert                                                                                        |
| SYS.2.2.3.A6:<br>Integration von Online-Konten in das Betriebssystem      | Anmeldungen mit lokalen Konten SOLLTEN Administrierenden vorbehalten sein.                                                                                                                                                                                                  | nein      | IT-Abteilung  | Lokale Anmeldung für alle Benutzenden möglich (dokumentiert: "nur eine lokale Anmeldung möglich"); keine Beschränkung auf Administrierende dokumentiert                                   |
| SYS.2.2.3.A6:<br>Integration von Online-Konten in das Betriebssystem      | Online-Konten zur Anmeldung, etwa ein Microsoft-Konto oder Konten anderer Identitätsmanagementsysteme, DÜRFEN NICHT verwendet werden, da hier personenbezogene Daten an die Systeme Dritter übertragen werden.                                                              | ja        | IT-Abteilung  | Anmeldung mit Online-Konten gesperrt                                                                                                                                                      |
