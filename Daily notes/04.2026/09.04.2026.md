## Progress:

Kwizz Android — Ktor Client setup for sync:
- Added Ktor Client dependencies to `libs.versions.toml` (ktor 3.4.2, matching backend) and `app/build.gradle.kts`
- Added `INTERNET` permission and `usesCleartextTraffic="true"` to `AndroidManifest.xml` (required for HTTP in development)
- Created `data/remote/KwizzHttpClient.kt` — singleton `HttpClient(OkHttp)` with `ContentNegotiation` (JSON) and `Logging` plugins installed
- Created `data/remote/SyncModels.kt` — `@Serializable` remote data classes (`RemoteQuiz`, `RemoteQuestion`, `RemoteQuizWithQuestions`) kept separate from Room entities to avoid coupling DB schema to API contract
- Created `data/remote/SyncService.kt` with two suspend functions:
  - `browseQuizzes()` — `GET /quizzes/browse`, returns `List<RemoteQuizWithQuestions>`
  - `uploadQuiz(QuizWithQuestions)` — converts local entity to remote model, `POST /quizzes/upload`
  - `toLocal()` extension function converts downloaded remote quiz back to local Room entities
- Added `syncService: SyncService` to `AppContainer` interface and implementation (lazy-initialized)
- Backend uses `10.0.2.2:8080` as `BASE_URL` — special Android emulator address that routes to the host machine's localhost

Understood: what an HTTP **payload** is — the data in the body of a request or response (the content, not headers/metadata)
