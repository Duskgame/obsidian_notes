Set up dependencies
1. Add the following variable to your project `build.gradle` file:

```
buildscript {   ext {       ...       lifecycle_version = '2.5.1'   }}
```

2. Add the following dependency to the `app/build.gradle` file:

```
dependencies {    ...implementation "androidx.lifecycle:lifecycle-viewmodel-compose:$lifecycle_version"}
```
