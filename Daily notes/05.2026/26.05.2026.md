- **Problem:** Buttons in SAKE `index.html` not visually separated from the warning div — empty `<div>` between them does nothing and the grid has no bottom margin
  → Add `mt-4` to the warning div's class list and remove the empty `<div>` on line 64
- **Problem:** Tailwind v4 build error "Cannot apply unknown utility class `card`" — `.card-pad` used `@apply card` which references another custom `@layer components` class
  → Tailwind v4 `@apply` only resolves built-in utilities. Expand to the full utility list instead of composing custom classes.
- **Problem:** Tailwind v4 build error in Svelte `<style>` blocks — utilities not found in `@apply`
  → Add `@reference "tailwindcss";` at the top of the `<style>` block. Without it, scoped styles can't see Tailwind utilities.
- **Problem:** pnpm 11 warns "The `pnpm` field in package.json is no longer read" — `onlyBuiltDependencies` ignored
  → Set `allowBuilds.esbuild: true` in `pnpm-workspace.yaml` instead. The `package.json` `pnpm` field is deprecated in pnpm 11.
