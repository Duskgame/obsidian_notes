## Problems:
- **Problem:** No styling visible after starting dev server in `wip-gcp-project-key-rotation_test2`
  → `@tailwindcss/vite` was missing from `vite.config.ts`. Tailwind v4 requires this Vite plugin to process `@import 'tailwindcss'` — without it, the import is a no-op and no CSS is generated. Fix: `pnpm add -D @tailwindcss/vite` and add `tailwindcss()` before `sveltekit()` in the plugins array.
- **Problem:** `pnpm install` failed with `ERR_PNPM_IGNORED_BUILDS` for `esbuild`
  → `pnpm-workspace.yaml` contained a placeholder `esbuild: set this to true or false` under `allowBuilds`. Changed to `esbuild: true`. The install itself succeeds without approval but esbuild's native binary is not built, causing it to silently fail at runtime.
