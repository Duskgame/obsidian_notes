| DROP INDEX            | DROP INDEX table_name.index_name _(SQL Server)_  <br>DROP INDEX index_name ON table_name _(MS Access)_  <br>DROP INDEX index_name _(DB2/Oracle)_  <br>ALTER TABLE table_name DROP INDEX index_name _(MySQL)_                                                                                                                                                                 |

| INSERT INTO           | INSERT INTO table_name  <br>VALUES (value1, value2, value3,....)<br><br>_or_<br><br>INSERT INTO table_name  <br>(column1, column2, column3,...)  <br>VALUES (value1, value2, value3,....)                                                                                                                                                                                     |

| NOT                   | SELECT column_name(s)  <br>FROM table_name  <br>WHERE NOT condition<br><br>or<br><br>WHERE column_name NOT IN (value1, value2,..)  <br>WHERE column_name NOT BETWEEN value1 AND value2  <br>WHERE column_name NOT LIKE pattern                                                                                                                                                 |
| NOT NULL              | CREATE TABLE table_name (  <br>column_name datatype NOT NULL  <br>)<br><br>or<br><br>ALTER TABLE table_name  <br>MODIFY COLUMN column_name datatype NOT NULL                                                                                                                                                                                                                  |

| PRIMARY KEY           | CREATE TABLE table_name (  <br>column_name datatype PRIMARY KEY,  <br>...  <br>)<br><br>or<br><br>CREATE TABLE table_name (  <br>column_name datatype,  <br>...  <br>CONSTRAINT pk_name PRIMARY KEY (column1, column2)  <br>)                                                                                                                                                  |
