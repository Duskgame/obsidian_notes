# TypeScript in Svelte

[Svelte Docs — TypeScript](https://svelte.dev/docs/svelte/typescript) | [SvelteKit Docs — Types](https://kit.svelte.dev/docs/types)

TypeScript can be used directly in Svelte files — simply add `lang="ts"` to the script tag. SvelteKit is designed for TypeScript out of the box.

---

## Basic setup

```svelte
<!-- lang="ts" enables TypeScript -->
<script lang="ts">
  let count: number = $state(0);
  let label: string = $derived(count === 1 ? "time" : "times");
</script>
```

---

## Types for $state and $derived

```svelte
<script lang="ts">
  // Explicit type
  let name = $state<string>("");

  // TypeScript infers the type automatically
  let count = $state(0);           // number
  let active = $state(false);      // boolean

  // Arrays and objects
  let keys = $state<string[]>([]);
  let user = $state<User | null>(null);

  // With interface
  interface ServiceAccountKey {
    id: string;
    serviceAccount: string;
    expires: string;
    isExpired: boolean;
  }

  let selectedKey = $state<ServiceAccountKey | null>(null);
</script>
```

---

## Types for props ($props)

```svelte
<!-- KeyCard.svelte -->
<script lang="ts">
  interface Props {
    keyId: string;
    serviceAccount: string;
    expires: string;
    onDelete?: () => void;           // optional
    variant?: "default" | "danger";  // union type
  }

  let {
    keyId,
    serviceAccount,
    expires,
    onDelete,
    variant = "default",             // default value
  } = $props<Props>();
</script>
```

## SvelteKit-generated types ($types)

SvelteKit automatically generates types for each route under `.svelte-kit/types/`. These can be imported:

```ts
// src/routes/keys/+page.ts
import type { PageLoad } from './$types';

export const load: PageLoad = async ({ params, fetch }) => {
  return { keyId: params.keyId };
};
```

```svelte
<!-- src/routes/keys/+page.svelte -->
<script lang="ts">
  import type { PageData } from './$types';

  let { data } = $props<{ data: PageData }>();
  // data.keyId is type-safe
</script>
```

Available `$types`:
- `PageLoad` — type for `+page.ts` load function
- `LayoutLoad` — type for `+layout.ts` load function
- `PageData` — type for `data` prop in `+page.svelte`
- `LayoutData` — type for `data` prop in `+layout.svelte`

## Utility types for Svelte

```ts
import type { Component, Snippet } from 'svelte';

// Type for a Svelte component
let MyComp: Component;

// Type for a snippet (Svelte 5)
let header: Snippet;
let itemSnippet: Snippet<[{ id: string; name: string }]>; // with parameter
```

## tsconfig.json

SvelteKit automatically creates a `tsconfig.json`:

```json
{
  "extends": "./.svelte-kit/tsconfig.json",
  "compilerOptions": {
    "strict": true,
    "moduleResolution": "bundler"
  }
}
```

The `.svelte-kit/tsconfig.json` is generated by SvelteKit and contains path aliases like `$lib`.

## Common TypeScript patterns in Svelte

### Event handler types

```svelte
<script lang="ts">
  function handleInput(e: Event) {
    const target = e.currentTarget as HTMLInputElement;
    console.log(target.value);
  }

  function handleSubmit(e: SubmitEvent) {
    e.preventDefault();
  }
</script>

<input oninput={handleInput} />
<form onsubmit={handleSubmit}></form>
```

### Async functions

```svelte
<script lang="ts">
  async function fetchKey(id: string): Promise<ServiceAccountKey> {
    const res = await fetch(`/api/keys/${id}`);
    return res.json() as Promise<ServiceAccountKey>;
  }
</script>
```

### Enums and union types

```ts
// src/lib/types.ts
export type UserRole = "requester" | "supporter" | "admin";

export interface KeyRequest {
  jiraTicket: string;
  serviceAccountEmail: string;
  expiresInDays: number;
  status: "pending" | "approved" | "rejected";
}
```
